# Planner Financeiro | Sistema de Controle de Gastos

Um painel de controle financeiro moderno e interativo desenvolvido com uma estética minimalista de planner, combinando elegância visual com lógica robusta em JavaScript puro. Projeto desenvolvido para o curso de Sistemas para a Internet.

## Funcionalidades

* **CRUD Completo**: Adicione, edite e exclua movimentações financeiras dinamicamente.
* **Filtros em Tempo Real**: Busque por descrição ou valor e filtre simultaneamente por categoria e tipo (entrada ou saída).
* **Cálculos Automáticos**: Resumo instantâneo de entradas, saídas e saldo restante atualizado a cada alteração.
* **Formatação Monetária**: Conversão automática para o padrão de moeda brasileira (BRL).
* **Interface Responsiva e Estética**: Design inspirado em cadernos de planejamento, com paleta de cores pastel e efeitos visuais refinados.

## Tecnologias Utilizadas

Este projeto foi construído utilizando apenas tecnologias nativas (Vanilla), focando no domínio de manipulação do DOM e boas práticas de programação:

* **HTML5**: Estruturação semântica da aplicação (SPA).
* **CSS3**: Estilização personalizada, layout flexível e design system próprio.
* **JavaScript (ES6+)**:
* Manipulação de Arrays avançada (`map`, `filter`, `reduce`).
* Imutabilidade de estado com o Spread Operator (`...`).
* Event Listeners em tempo real.



## Como Executar o Projeto

Para rodar o projeto localmente na sua máquina, siga os passos abaixo:

1. Clone este repositório:
```bash
git clone https://github.com/isaave/Sistema-de-controle-de-gastos.git

```


2. Abra a pasta do projeto no seu editor de código (como o VS Code).
3. Abra o arquivo `index.html` diretamente no seu navegador de preferência ou utilize a extensão Live Server.
